# Awesome Fable Game

社区里流传的、据称由 Claude Fable 5.2 辅助制作的可玩游戏索引。

A short index of browser-playable games that people in the community say were made with help from Claude Fable 5.2. This list does not independently verify the model, the toolchain, or any release timeline.

本仓库只做索引。游戏和素材的权利归原作者。收录不代表已经审核授权，也不代表我们已试玩或背书。想玩请前往作者公布的链接，并尊重原作者的许可和意愿。

## 游戏

- **[Starry Nightrider](https://starrynightrider.com/)** — 骑车穿行于梵高《星夜》画中，收集光球送到教堂尖塔。作者 [@ebbyamir](https://x.com/ebbyamir) · [演示帖](https://x.com/ebbyamir/status/2120284261089673376)
- **[Saltline](https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp)** — 雨夜码头第一人称射击，据作者称模型、贴图和音效均由代码生成。作者 [@felixrieseberg](https://x.com/felixrieseberg) · [演示帖](https://x.com/felixrieseberg/status/2119925633564463609)
- **[What the Water Keeps](https://what-the-water-keeps.vercel.app/)** — 提灯乘船穿过多个梦境世界的慢节奏航行，没有胜负目标。作者 [@kevin_t_ngo](https://x.com/kevin_t_ngo) · [演示帖](https://x.com/kevin_t_ngo/status/2119868968307695818)
- **[MIRROR EARTH](https://www.spawn.co/@mattshumer/earth?room=local)** — 以地球为舞台的体素沙盒，可漫游和破坏；作者称天气会对照真实地球。作者 [@mattshumer_](https://x.com/mattshumer_) · [演示帖](https://x.com/mattshumer_/status/2119877065701036047)
- **[Portals](https://portals-endless-worlds.netlify.app/)** — 由传送门串起来的无尽 3D 世界漫游。据作者称，大量 agent 生成了数百个以书籍、艺术和地点为灵感的世界。作者 [@emollick](https://x.com/emollick) · [演示帖](https://x.com/emollick/status/2119918307457577163)
- **[Evensong](https://evensong-phi.vercel.app/)** — 淹没大教堂里的类魂式 Boss 对决演示。作者 [@kevin_t_ngo](https://x.com/kevin_t_ngo) · [演示帖](https://x.com/kevin_t_ngo/status/2120238844754923874)
- **[Siege Wing](https://bannerfall.itch.io/siege-wing)** — 驾驶武装直升机，在时限内攻打中世纪城堡与敌军。作者 [@builderjaydub](https://x.com/builderjaydub) · [演示帖](https://x.com/builderjaydub/status/2120223731520040966)
- **[I Would Have Gotten Away With It](https://i-would-have-gotten-away-with-it.netlify.app/)** — 反向史酷比：你扮演怪物，吓跑多管闲事的小孩。作者 [@emollick](https://x.com/emollick) · [演示帖](https://x.com/emollick/status/2119876449494540554)
- **[Gilt & Gutter](https://gilt-and-gutter.vercel.app/)** — 子弹分金/青绿两色的 1v1 第一人称对决。作者 [@kevin_t_ngo](https://x.com/kevin_t_ngo) · [演示帖](https://x.com/kevin_t_ngo/status/2119900487688622171)
- **[Hogwarts Royale](https://www.spawn.co/@mattshumer/hogwarts-royale)** — 哈利波特与堡垒之夜风格的非官方同人吃鸡，骑扫帚对战。作者 [@mattshumer_](https://x.com/mattshumer_) · [演示帖](https://x.com/mattshumer_/status/2119872098306810226)
- **[Dread & District](https://dread-and-district.netlify.app/)** — 奇幻世界里的交通调度模拟：把聚落连起来，用物流对抗混乱。作者 [@emollick](https://x.com/emollick) · [演示帖](https://x.com/emollick/status/2120248525254742318)
- **[Turbo Tails](https://turbo-tails.vercel.app/)** — 浏览器里就能玩的 3D 卡丁车，多条赛道，可与朋友对战。作者 [@petergyang](https://x.com/petergyang) · [演示帖](https://x.com/petergyang/status/2119901658394358005)
- **[Banana Mine Rush](https://remix.gg/g/banana-mine-rush)** — Remix 平台上的矿车竞速，浏览器即开即玩。作者 [@0xChuckstock](https://x.com/0xChuckstock) · [演示帖](https://x.com/0xChuckstock/status/2120125184606658728)

## 游戏合集与发现

- **[DSH 游戏商店](https://dsh-game-store.com/)** — 一个面向「大家用 Agent 做的游戏」的网页商店和发现平台。目录里的游戏可以在浏览器里打开就玩，也可以按站点说明投稿上架。这里把它当作合集入口列出，不是单款游戏。

## 收录规范

欢迎补充新条目。请尽量满足：

1. 有可直接打开的试玩链接（不要只放视频）。
2. 写明作者，并链到其公开主页或账号。
3. 链到作者或可靠公开来源的演示原帖。
4. 用一句话说明类型；不要写未经核实的热度数字，也不要把未经证实的模型身份或发布时间写成事实。
5. 合集、平台或商店请放在「游戏合集与发现」，不要当成单款游戏。

新条目可以按这个格式写：

```markdown
- **[游戏名](可玩链接)** — 一句话类型介绍。作者 [@账号](https://x.com/账号) · [演示帖](https://x.com/账号/status/...)
```

提交 Issue 或 Pull Request 即可。
